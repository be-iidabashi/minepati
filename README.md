# MinePati - Minecraft Clone

PythonとUrsina Engineを使用して作成された、シンプルで安定したMinecraftの再現プロジェクトです。

## ディレクトリ
`/Users/been01y/Desktop/tobinai haruma/3年目/minepati/minepati`

## 操作方法
- **WASD**: 移動
- **Space**: ジャンプ
- **マウス**: 視点移動
- **左クリック**: ブロックを壊す
- **右クリック**: ブロックを置く
- **1, 2, 3, 4**: ブロックの種類を切り替える（芝生、土、石、レンガ）
- **ESC**: ゲームを終了する

## 実行方法
```bash
pip install ursina
python minecraft.py
```
